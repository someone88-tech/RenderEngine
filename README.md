# RenderEngine：高性能跨平台全场景小游戏/小程序容器解决方案,高性能图形渲染引擎 

[![Platform](https://img.shields.io/badge/Platform-iOS%20%7C%20Android%20%7C%20HarmonyOS%20%7C%20Windows%20%7C%20Linux%20%7C%20macOS-blue.svg)](#)

**RenderEngine** 是一款专为跨平台 打造的**高性能图形渲染引擎**与**跨平台插件化容器**。它能够帮助开发者以“低代码”方式，快速在自有 App 中嵌入运行微信小程序和小游戏，实现极致的加载速度与原生级别的操控体验。

---

## ✨ 核心优势

* **⚡ 极致渲染性能**：自研高性能渲染内核，帧率稳定，深度优化 DrawCall，性能媲美原生游戏。
* **兼容全生态**：完美兼容 **微信小程序/小游戏** 标准协议，支持 Cocos Creator、LayaAir、Egret (白鹭)、Unity、PixiJS、Threejs、Godot 等主流开发工具导出的项目。
* **🧩 极简集成 (低代码)**：提供轻量级 SDK，最快一行代码即可在原生 App 中唤起小游戏运行环境。
* **🔄 动态发布与热更新**：支持游戏内容云端分发，无需通过 App Store/应用商店审核即可实时更新业务逻辑。
* **跨平台支持**：一套代码多端运行，全面覆盖 iOS、Android 以及鸿蒙 (HarmonyOS)、Windows、Mac、Linux 系统。

---

## 🛠 技术特性

- **双线程架构**：逻辑层与渲染层分离，确保复杂计算不阻塞 UI 交互。
- **原生能力桥接**：支持调用相机、定位、蓝牙、传感器等原生底层能力。
- **资源预加载体系**：自研资源缓存与并发下载策略，实现小游戏“秒开”体验。
- **内存隔离机制**：沙箱化运行环境，确保小游戏运行不影响宿主 App 的稳定性。

---

## 📂 典型应用场景

1.  **App 游戏化营销**：在电商、金融、生活服务类 App 中快速植入养成系、抽奖类互动小游戏，提升活跃与留存。
2.  **自有生态构建**：效仿微信打造自有的小程序/小游戏分发平台，吸引第三方开发者入驻。
3.  **互动广告方案**：在 App 广告位中展示可玩性极强的试玩广告。
